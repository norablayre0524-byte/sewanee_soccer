# sewanee_soccer

Examining soccer statistics is an excellent way to understand a team's strategies and how effective these strategies are. This data story utilizes two shiny apps to collect data, one for attacking stats and one for defensive stats. These data frames contain entries from the first 10 minutes of Sewanee Men's Soccer team's spring exhibition game against Dalton State. The exciting clash revealed a lot about Sewanee's playstyle and how the young team can capitlize on their talent pool for the next few seasons.
